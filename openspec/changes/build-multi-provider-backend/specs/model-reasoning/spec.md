# Spec Delta

## Purpose

定义按供应商、接口协议和准确模型标识匹配的原生思考控制，覆盖主流国内外模型家族，避免将未经证实的档位或预算发送给不支持的模型和聚合站。

## ADDED Requirements

### Requirement: 内置能力
系统 SHALL 为 OpenAI、Claude、Gemini、DeepSeek、Qwen、Kimi、GLM 的已核实型号内置思考能力，记录型号、别名、合法档位、预算范围、输出限制、默认行为及来源，不按名称片段推测能力。

#### Scenario: 未知型号
- **WHEN** 用户添加未登记的模型 ID
- **THEN** 允许普通聊天尝试，但不显示未经核实的思考控制

### Requirement: 原生参数与校验
系统 SHALL 按型号及接入协议显示档位、预算或开关，支持合法的组合，默认沿用供应商默认参数，对非法设置返回错误且不静默换档。

#### Scenario: 强制思考
- **WHEN** 用户选择不能关闭思考的型号
- **THEN** 不提供关闭入口，直接请求关闭也被后端拒绝

#### Scenario: 非法预算或档位
- **WHEN** 设置不支持的档位、超范围预算或与输出上限冲突的预算
- **THEN** 提交前提示，后端再次校验并拒绝无效生成

### Requirement: 上游兼容与上下文
系统 SHALL 按接入适配配置转换思考字段，正文与思考内容分离，保留同一供应商与模型续接需要的原生内容和签名，不跨不兼容配置传递签名。

#### Scenario: 多轮思考
- **WHEN** 同一供应商与模型继续多轮聊天且需要原生思考块或签名
- **THEN** 后端原样续接，前端回答正文不混入思考文本
