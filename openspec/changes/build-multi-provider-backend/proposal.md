# Proposal

## Why

现有独立 Mock 聊天前端尚不能接入真实供应商，也没有用户登录和供应商设置界面。建立 Go 多用户后端，使用户以自己的密钥连接不同协议的模型，并可靠保存聊天历史和原生思考参数。

## What Changes

- 建立 Go、chi、PostgreSQL、pgx、sqlc、goose 单实例后端，使用已授权的开发数据库；保留独立 Mock 模式。
- 新增用户名密码注册、七天会话、退出和修改密码，隔离每个用户的配置与历史。
- 提供四种模型协议、官方和常见聚合站模板、手动填写供应商、模型发现与手动添加。
- 新增七个模型家族的内置能力注册表，按真实能力展示档位、预算与开关。
- 接入数据库历史、NDJSON 生成、确定性停止、失败重试和重启恢复。
- 新增 Claude 风格的供应商、模型和账号设置页；真实模式以用户启用的模型替代固定 Mock 名称。
- 本轮不包含附件、知识库、工具调用、计费、第三方登录、邮件找回、配置文件导入、平台共享密钥和管理员控制台。

## Capabilities

### New Capabilities

- `user-auth`: 注册、会话、密码和用户数据隔离。
- `provider-management`: 私人供应商、密钥、模板、模型和默认偏好。
- `model-reasoning`: 协议与模型能力匹配和原生思考参数验证。
- `backend-chat`: 服务端对话保存与可取消的流式生成。
- `settings-interface`: 真实模式模型选择和响应式设置界面。

### Modified Capabilities

无已归档主规格；现有 build-chat-frontend 保持独立 Mock 范围及其未完成实机验收。

## Impact

新增 server/ Go 模块及数据库迁移；扩展前端统一 API、登录边界、菜单和设置路由，增加后端及真实服务浏览器测试。新增依赖核对兼容 AGPL-3.0-only 的许可证。凭据仅写忽略的本地环境文件，第三方 API 密钥加密入库，不自动提交、推送或归档。
