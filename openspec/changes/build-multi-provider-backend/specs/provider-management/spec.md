# Spec Delta

## Purpose

定义用户私有的供应商、API 密钥、模型和默认偏好管理，使用户能够使用官方接口、聚合站模板或自己的地址接入模型，并在网络失败时保留已经保存的配置。

## ADDED Requirements

### Requirement: 私人配置与模板
系统 SHALL 提供 OpenAI、Gemini、Anthropic、OpenRouter、硅基流动、New API、One API 模板及自定义供应商，支持名称、协议、地址、密钥、启用状态的保存、修改及删除。

#### Scenario: 保存与更新
- **WHEN** 用户保存供应商并刷新，或不填写新密钥进行修改
- **THEN** 恢复已保存配置，更新不清除已有密钥；读取接口仅返回密钥配置状态

### Requirement: 密钥与地址保护
系统 MUST 加密保存 API 密钥，仅由后端调用上游；默认允许公网 HTTPS，内网目的地必须由服务器允许列表授权，禁止跨地址重定向。

#### Scenario: 不安全目的地
- **WHEN** 用户提供未获允许的内网、回环、特殊用途地址或上游重定向
- **THEN** 拒绝调用且不向目标泄露 API 密钥

### Requirement: 模型发现及手动添加
系统 SHALL 支持获取供应商模型列表、手动添加模型、启停模型、默认模型和原生思考参数及输出上限的配置。

#### Scenario: 发现失败
- **WHEN** 上游不支持模型列表或网络失败
- **THEN** 显示中文反馈，保留供应商配置，允许手动添加模型

#### Scenario: 模型不可用
- **WHEN** 模型或所属供应商已停用或删除
- **THEN** 不允许新生成，不静默替换为其他模型，历史仍可阅读
