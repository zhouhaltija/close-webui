# Spec Delta

## Purpose

定义真实用户登录后的模型配置和中文浅色设置体验，在桌面和移动端提供供应商、模型和账号管理，保持 CloseWebUI 品牌和现有聊天交互及可访问性。

## ADDED Requirements

### Requirement: 响应式设置
系统 SHALL 提供供应商、模型、账号三个设置分类，采用 Claude 风格浅色导航与内容面板，桌面左右布局、移动顶部导航，所有控件使用中文反馈并可键盘操作。

#### Scenario: 窄屏与键盘
- **WHEN** 在 390px 或桌面使用设置页并通过 Tab 或 Escape 操作
- **THEN** 无页面横向溢出，控件可见，弹层有焦点约束及恢复

### Requirement: 真实模型菜单
系统 SHALL 在真实模式展示当前用户启用模型及其原生思考控制，发送时固定参数，切换模型恢复该模型默认设置。

#### Scenario: 未配置模型
- **WHEN** 登录用户没有可用模型
- **THEN** 显示设置入口并禁用发送，不将固定 Mock 名称当作真实连接

### Requirement: 身份与模式边界
系统 SHALL 提供侧栏用户菜单、设置和退出入口，退出取消生成并清空私人状态；独立 Mock 模式保留，真实模式不自动导入或覆盖旧浏览器历史。

#### Scenario: 退出与重新登录
- **WHEN** 用户退出后另一用户登录
- **THEN** 新用户不会看到旧用户的缓存、选择、密钥、草稿或历史
