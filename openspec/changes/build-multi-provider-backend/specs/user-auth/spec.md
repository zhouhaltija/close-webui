# Spec Delta

## Purpose

定义多用户聊天平台的注册、登录、密码和会话行为，保证每位用户只能访问自己的聊天历史及供应商配置，并在退出或身份失效后清除浏览器中的私人状态。

## ADDED Requirements

### Requirement: 注册与登录
系统 SHALL 支持用户名密码注册、登录和退出，密码安全散列保存，会话有效期七天且仅通过 HttpOnly Cookie 传递。

#### Scenario: 注册成功
- **WHEN** 用户提交有效且未占用的用户名和密码
- **THEN** 创建账号并登录；重复用户名被拒绝，错误密码不给出会话

#### Scenario: 会话失效
- **WHEN** 会话过期或退出后访问受保护接口
- **THEN** 返回 401；前端回到登录页并清除私人缓存和草稿

### Requirement: 修改密码
系统 SHALL 验证当前密码后修改密码并注销该用户全部已有会话。

#### Scenario: 修改成功
- **WHEN** 用户提交正确的旧密码及有效新密码
- **THEN** 保存新密码并要求重新登录，其他设备的旧会话也失效

### Requirement: 用户隔离
系统 SHALL 按当前用户归属限制对话、消息、供应商、模型及偏好的全部操作，不允许通过猜测 ID 访问其他用户的数据。

#### Scenario: 跨用户访问
- **WHEN** 用户访问其他用户拥有的资源 ID
- **THEN** 返回 404 且不泄露存在性、密钥或聊天内容
